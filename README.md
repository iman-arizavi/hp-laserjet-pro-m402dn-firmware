# HP LaserJet Pro M402dn Firmware

Documentation and official firmware resources for the **HP LaserJet Pro M402dn** printer.

## Official HP Downloads

- [HP LaserJet Pro M402dn — Drivers and Firmware](https://support.hp.com/nz-en/drivers/hp-laserjet-pro-m402-m403-n-dn-series/model/7458632)
- [HP LaserJet Pro M402/M403 Series Support](https://support.hp.com/us-en/drivers/hp-laserjet-pro-m402-m403-n-dn-series/7458627)

Use HP's official site to verify the newest firmware package available for your exact printer and operating system. This repository does not redistribute HP firmware binaries.

## How to update firmware

1. Open one of the official HP support links above.
2. Confirm the selected printer is **HP LaserJet Pro M402dn**.
3. Choose your operating system if prompted.
4. Open the Firmware section, if available, and read the release notes.
5. Download the firmware package supplied by HP.
6. Confirm that the package supports the exact printer model and follow HP's included instructions.
7. Ensure the printer has a stable power supply and connection.
8. Run the official updater or use the installation method described by HP.
9. Do not turn off the printer or interrupt the connection during the update.
10. After the printer restarts, print a configuration page and verify the firmware revision.

## Safety and troubleshooting

- Only use firmware obtained from official HP sources.
- Never install firmware for a different printer model.
- Do not interrupt a firmware update.
- Firmware downgrades may be unsupported or restricted.
- If the update fails, record any displayed error, verify model compatibility, and consult HP Support.
