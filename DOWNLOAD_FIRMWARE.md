# Official Firmware Download

For the HP LaserJet Pro M402dn, get firmware directly from HP:

- [HP support page for M402dn](https://support.hp.com/nz-en/drivers/hp-laserjet-pro-m402-m403-n-dn-series/model/7458632)
- [HP LaserJet Pro M402/M403 series drivers and firmware](https://support.hp.com/us-en/drivers/hp-laserjet-pro-m402-m403-n-dn-series/7458627)

Select the exact printer model and your operating system. Check the version and release notes before downloading and installing.

**Important:** This repository contains documentation only. It does not include an HP firmware binary or a fabricated ZIP package. Firmware packages should be downloaded directly from HP so their authenticity and compatibility can be verified.
